# Документация

Документы разделены по области, чтобы при реализации читать только нужный контекст:

- `architecture/` — границы модулей, торговый автомат и модель данных;
- `integrations/` — внешние контракты Google Sheets и T‑Invest;
- `operations/` — risk/security, тестирование и развёртывание;
- `planning/` — roadmap и нерешённые продуктовые вопросы.

Обязательные для кода правила находятся в корневом и локальных `AGENTS.md`. Документы здесь являются подробными спецификациями, а не автоматически загружаемым набором инструкций.
