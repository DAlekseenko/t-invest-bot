# AGENTS.md

## Область действия

Здесь находятся только инварианты для всего репозитория. Перед изменением модуля прочитай ближайший к нему `AGENTS.md` и только относящиеся к задаче документы из `docs/`; не загружай всю документацию сразу.

## Глобальные ограничения безопасности

- Безопасный режим по умолчанию — `disabled`; переход в `live` никогда не происходит автоматически.
- Тесты, локальная разработка и CI не обращаются к production trading methods и не выставляют реальные заявки.
- В MVP запрещены market/best-price orders, margin trading и short selling.
- Токены, credentials, полный account ID и неочищенные внешние payload не попадают в код, Git и логи.
- Деньги и цены представлены fixed-point значениями, совместимыми с `Quotation` (`units` + `nano`), количества — целыми единицами/лотами; `float32`/`float64` для них запрещены.
- Google Sheets — control plane, но не источник факта исполнения. Источник локального состояния — PostgreSQL, сверенный с брокером.
- Команда выставления, замены или отмены сначала фиксируется в БД. Любая внешняя команда идемпотентна.
- После неопределённого результата запрещён повтор `PostOrder` с новым idempotency key; сначала выполняется reconciliation.
- Базовая позиция защищена. `sell_scope=entire_position` запрещён без отдельного ADR и ручного review.
- Обычная ошибка, stale data или потеря stream не запускают автоматическую массовую отмену заявок.

## Изменения повышенного риска

Отдельный ADR и ручной review обязательны для продажи базовой позиции, margin/short, market/best-price orders, автоматического нового цикла, массовой отмены заявок, смены source of truth и нескольких активных trader instances.

## Проверка изменений

Для Go-кода запускай применимые проверки: `go test ./...`, `go test -race ./...`, `go vet ./...`, `golangci-lint run`. Если проект ещё не содержит нужного инструмента или конфигурации, явно укажи, что именно не удалось запустить.
