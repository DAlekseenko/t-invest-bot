# Правила для `internal/`

- Core domain не импортирует Google или T‑Invest SDK и не использует protobuf-типы.
- Внешние зависимости доступны через узкие интерфейсы: `ConfigProvider`, `Broker`, `MarketDataProvider`, `Repository`, `Notifier`.
- `context.Context` — первый аргумент каждого I/O-метода; чистые доменные вычисления context не принимают.
- Для времени используется UTC, а торговое расписание и статус берутся из broker API.
- Ошибки оборачиваются с контекстом без секретов и полного account ID.
- У каждой goroutine должен быть владелец, отменяемый context и сценарий завершения.
- Конфигурация применяется только целым immutable snapshot.
- Переходы доменного автомата и связанные audit/outbox записи выполняются транзакционно.
