# Правила хранения

- PostgreSQL — источник локального состояния исполнения; Google Sheets не используется для восстановления заявок.
- Выбери одно fixed-point представление (`BIGINT` nano units или `NUMERIC(28,9)`) до первой миграции и используй его последовательно.
- Время хранится как `TIMESTAMPTZ` в UTC; broker IDs — как непрозрачные строки.
- Изменение state, audit event и outbox event фиксируются одной транзакцией.
- Критичные доменные инварианты дублируются ограничениями БД.
- Внешние payload сохраняются только после redaction; audit для приложения append-only.
- Конкурентные переходы защищаются row/advisory locks и проверяемыми версиями.
- Модель данных описана в `docs/architecture/data-model.md`.
