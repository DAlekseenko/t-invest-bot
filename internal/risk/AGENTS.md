# Правила Risk Engine

- Если безопасность команды нельзя доказать, возвращай запрет; недоступность предпочтительнее неопределённой операции.
- Проверяй каждую торговую команду непосредственно перед исполнением по актуальному broker/reconciliation state.
- BUY не превышает лимиты заявки, резерва и оборота и не требует margin.
- SELL не превышает свободную позицию, разрешённый ladder inventory и не затрагивает protected base.
- `pause_new_orders` запрещает PLACE/REPLACE, но сам по себе не отменяет заявки.
- `cancel_open_orders` — отдельная ручная scoped-операция только для заявок сервиса.
- Каждое решение сохраняет reason codes для аудита.
- Политика проверок описана в `docs/operations/risk-and-security.md`.
