# Правила конфигурации

- Применяй только опубликованный, одобренный и целиком провалидированный immutable snapshot.
- Одна revision не может менять нормализованный hash; такое изменение блокируется как `REVISION_MUTATED`.
- Невалидная новая revision не изменяет активный snapshot.
- `live` требует всех независимых разрешений; отсутствие любого из них означает запрет торговых методов.
- Не помещай секреты и реальный account ID в пользовательскую конфигурацию.
- Контракт и нормализация описаны в `docs/integrations/google-sheets.md`; читай его при изменении схемы.
